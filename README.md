# PruebaPracticaPOO
Por medio de este repositorio se subirá los archivos pertinentes del examen de la unidad 3 de la materia de algoritmos y lógica de programación.

Donde Este proyecto es una aplicación de consola desarrollada en C++ diseñada para la gestión académica básica y operaciones matemáticas. El sistema permite realizar cálculos rápidos y gestionar el registro de notas para un grupo predefinido de 39 estudiantes, generando automáticamente un reporte detallado en un archivo de texto.

**Gestión Académica:**

Listado predefinido de 39 alumnos.  

Ingreso de 4 notas por cada estudiante.  

Cálculo automático de promedio y estado (Aprobado/Reprobado) basado en una nota mínima de 7.0.  

Persistencia de Datos: Genera un archivo llamado resultados.txt con el reporte académico completo y un resumen estadístico del grupo.
